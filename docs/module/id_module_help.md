## 解决方法

1. `assign` 持续赋值语句，用来描述组合逻辑电路
使用 `assign` 语句赋值时，标记为 `wire` 变量。  
2. `always` 过程块，包含过程语句，重复执行
使用过程语句给信号赋值时标记为 `reg` 变量。  
`reg` 变量不等于触发器、寄存器，`reg` 类型的变量是一个用于建模行为的抽象，它不代表具体的硬件电路元件。而触发器和寄存器是实际硬件电路中的物理组件，它们能够存储二进制信息。  
一旦在仿真过程中给一个 `reg` 变量赋值，仿真器会在当前仿真时间步结束时"记住" 这个值，并在下一个时间步开始时仍然保持这个值，直到该变量被赋予新值。  
在硬件描述语言中，通常使用非阻塞赋值（如 `<=`）来给 `reg` 变量赋值，这表示在当前时间步结束时更新变量的值。  
3. `{}` 位拼接运算符，用于位的重组和矢量构造，拼接时不限定操作数的数目。在操作符符号 `{}` 中，用逗号将操作数分开，如：`{a,b,c,d}`
可以在赋值号左边，也可以右边。

5. 区别普通的译码器和CPU译码逻辑模块  
译码器是一种较为简单的数字电路，它的主要功能是将输入的二进制代码翻译成对应的输出信号。译码器通常用于小规模的输入到输出映射，它们在数字电路中作为接口电路，将微处理器的控制信号转换为更宽的输出信号，用于驱动其他电路。  
例如，一个2-to-4译码器可以将2位二进制输入转换为4个输出中的一个，每个输出对应一个特定的输入组合。  
CPU译码逻辑模块是CPU内部的一个复杂组件，它负责将指令操作码解码成控制信号，这些信号用于控制CPU内部的数据路径和其他功能单元，以执行指令。  
这个模块不仅仅进行简单的译码操作，它还可能包括指令解析、寻址模式计算、指令调度等多种功能。
