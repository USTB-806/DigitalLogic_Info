# ALU 实验帮助

> by 姚超宇

+ **理解 ALU 的电路组成**：可以通过搭建由多个模块组成的电路图去理解，或者搞个方法能在电路上观察到数据怎么流通变化的过程。
+ **从电路到代码实现的跨越**：在前面已经理解清楚了每个模块功能的前提下，主要是语法上的问题，具体的功能怎么去实现，比如说独热码对计算方法的选择功能，就要求对 verilog 中的分支语句写法比较熟练。
+ **debug 的问题**：代码写完了拿过去提交，结果没过，语法上也没报错，找不到自己代码出问题的地方，自己写测试用例，往往会漏掉一些考虑的情况。
+ 很多问题其实是在写代码的时候才发现的，这些问题往往解决得很慢。
  
我得到的出错提示：

+ 编译器直接标注出来的错误，因为是初学者对标注出的错误原因往往自己是分析不出来的；我的解决办法一般是发给 AI 让它分析。

?> 此部分请自行根据编译器给出的报错分析，vivado 在大部分情况下给出的错误信息还是很明确的。

+ 用 CG 平台或综合不成功的错误：这直接就定位不到错误的位置了；这个我是对着文档反复看我对哪个计算的理解错误；我希望可以给些测试用例检验一下。

?> 关于测试用例的问题，建议自行设计测试用例，设计测试用例也是一种能力。如果实在不会设计，可以直接使用 ramdom 随机生成。

我觉得要快速掌握知识点的话做题还是最有效的办法；

电路不懂多在 logisim 上搭电路解题；

代码不会就练习语法题；（好像 hdlbit 网站可以用来练习）

我感觉我对逻辑电路组成理解会快一些，因为我之前玩了个叫作图灵完备的游戏（steam 上的），里面都是搭建复杂模块的关卡，一点点教你怎么从门电路搭建到 CPU 再到能实现游戏功能的电脑，和 logisim 很像，用于理解电路很有帮助，但有些地方涉及底层原理的地方就比较粗略，时间紧我不太推荐去玩，还是比较耗时的。
